# GoGoBCC

數概第三章 1–2 節複習，依使用者提供的 PDF 19 題與最後一頁答案製作。

## 開啟

雙擊「GoGoBCC-離線版.html」即可使用，無需安裝、連網或註冊帳號。也可將根目錄中的 index.html、JavaScript、CSS 與 hdmi.png 放上靜態網站主機。

## 學習機制

- 每次出題用 Fisher–Yates 洗牌，答案綁定原始選項，不綁定畫面字母。
- 每題答對一次立即過關，進度增加 1/19；答對的題目不再出現。提示後答對也算過關。
- 只有答錯的題目會在最多三道其他題目後重練；僅剩一題時可直接重練。錯題重練答對也增加進度。
- 每題過關得 10 糖分；進度以不同題目過關數計算，不以累計答題次數計算。
- 全部 19 題過關後自動顯示「滿分 100」與多波彩帶、飄帶動畫，可以重播慶祝。尊重減少動態效果偏好。
- 100 分表示學習完成度，不是首次作答正確率；完成畫面另列實際作答次數。
- 不顯示中途成果頁，持續作答到全部過關。
- 沿用原本瀏覽器存檔位置；舊版曾答對的題目會自動轉為已過關，不需重新答兩次。

## 題庫選單與進度

首頁目前提供「高一數概三-1~2」按鈕，之後新增單元會增加第二個題庫按鈕。

banks.js 是題庫清單；每個單元設定獨立 id、title、storageKey 與 questions。新增題庫時載入其題目並在清單加入一筆即可。各單元題數與進度條依題庫自動計算。

進度自動存於同一瀏覽器同一網站來源，不會自動同步到其他裝置。清除瀏覽資料或使用無痕視窗可能無法保留進度。共用電腦可使用不同瀏覽器個人檔案。

已移除所有進度／學習成果匯出功能。可匯入之前保存的相同單元舊進度；重設僅清除目前題庫進度。

## 題庫與答案

原始答案順序：C C D B C D D A A D C C A A B B C B A。

questions.js 保留原題題號、選項與答案索引。第 16 題圖片裁自原 PDF；第 19 題選項中的 USB 圖示轉為「USB 圖示」文字，其餘依原題內容整理標點。解析與口訣為系統補充，非原 PDF 內容。第 7、14、17 題解析補充適用情境，以原始答案表判分。

設計參考：[滙豐機滙：五個遊戲類 UI 設計技巧](https://www.businessgo.hsbc.com/zh-Hant/article/game_ui_design_skills)，運用簡單引導、答題頁進度、即時回饋與完成獎勵。糖果圖形以 CSS 原創，無 Candy Crush 品牌或官方素材。

## 維護與驗證

修改根目錄中的 HTML、CSS 與 JavaScript 檔案；用 node test-engine.cjs 驗證題庫答案、選項洗牌判分、錯題重排、提示判定、進度還原、全題及末題通關。GoGoBCC-離線版.html 是已整合程式、樣式及圖片的單檔版本。

鍵盤：Tab 移動，1–4 選答案，Esc 關閉視窗。支援手機排版、減少動態效果偏好，音效預設關閉。
